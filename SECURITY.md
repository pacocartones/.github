# Security policy

This is the default security policy for repositories owned by [@pacocartones](https://github.com/pacocartones) that do not have their own.

## Reporting a vulnerability

Please do **not** open a public issue, pull request or discussion for a security problem.

Report it privately through the repository's **Security** tab: **Report a vulnerability** ([GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Include:

- what is affected (file, endpoint, package version or commit);
- how to reproduce it, and what an attacker could do with it;
- any fix or mitigation you suggest.

You should get a first answer within a week. Once the issue is confirmed, a fix is prepared in private and a security advisory is published with credit to you, unless you prefer to stay anonymous.

## Supported versions

Unless a repository's README says otherwise, only the latest release (or the default branch, for projects without releases) receives security fixes.
